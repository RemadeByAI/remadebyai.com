    About Backroad Rally

    A free, non-commercial demo made in eleven vertical slices with three.js and Rapier physics. You race point-to-point stages against nine simulated rivals, who also run as ghosts. The maker links to art of rally, the game that inspired it.

    How it was built with AI

    The README says Claude Code with Claude Opus 5.5 wrote almost all of the game, first as a desktop version in Unreal Engine 5 in about four days, then as this web port.
