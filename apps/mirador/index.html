    About mirador

    mirador is built to sit in a terminal tab all day and be glanced at, so nothing blinks and only the focused panel is at full brightness. Its fourteen panels include world clocks, a two-month calendar and agenda, weather with an hourly forecast, a task list with due dates, priorities and tags, notes, news headlines, a calculator, a pomodoro timer, a market watchlist and CPU, memory and network charts. Panels can be turned off and rearranged from the keyboard.

    Tasks, notes and the watchlist are plain TOML files you own. There is no account, API key or telemetry, and update checks are off until you turn them on. Install it with cargo or the one-line installers for macOS, Linux and Windows.
