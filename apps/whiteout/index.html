    About WHITEOUT

    A blizzard is rising at dusk. Start generators A, B and C in any order, then send the call from the radio hut; if the stalker reaches you, you lose, and holding your flashlight on it for a moment makes it retreat.

    The whole game is one 1.15 MB HTML file with no images, models, textures or audio: every building, snowdrift, light and sound is generated in code. It wants desktop Chrome on a real GPU, or you can download the file and open it locally. The repo also holds the Claude Code skill that made it.
