    About Shanhe

    Fifty fictional nations follow real province-level borders across East Asia, Siberia and Southeast Asia, each taking its flavour from its place. A whole 150-turn game can already be played against the AI, with cities, combat, war and peace, a tech tree and three ways to win. Terrain comes from public elevation data and everything else is drawn by shaders, with no model or texture files.

    It is early: policies, diplomacy, trade and national traits are still to come, and there is no hosted build yet, so you clone it and run it with Node 24. The interface is in Chinese and English.

    How it was built with AI

    The README says the whole game, from design to code, is written by Claude (Fable) with a human owner making product decisions; Claude subagents deliver the work as pull requests. Checked 2026-11-28: the 32 commits are merged pull requests and carry no co-author lines, so this rests on the README.
