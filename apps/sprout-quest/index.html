    About Sprout Quest

    Best played on a phone held upright. Every armour piece changes how your hero looks, and axes and picks level up with you. The repo has no licence file, so the source is viewable but not openly licensed.

    Screenshots

    How it was built with AI

    The README says Sprout Quest was built entirely by Claude Opus 5.5 in Claude Code, starting on the model's release day: the code, the Blender art pipeline, every 3D model, the tests and CI. A human plays it and gives feedback; no code or art was written by hand. Checked 2026-11-22: 232 of 310 commits are co-authored by Claude.
