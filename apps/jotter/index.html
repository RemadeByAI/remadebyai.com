    About jOtter

    jOtter edits and runs .ipynb notebooks in a terminal and saves them byte for byte the way Jupyter does, so collaborators using JupyterLab never notice. It can also keep notebooks as .py scripts in jupytext's percent format so outputs stay out of git. Matplotlib figures show inline in terminals that support kitty graphics, sixel or iTerm2, LaTeX is rendered without a TeX install, and cells are edited with vim keys or an embedded Neovim using your own config.

    It finds your project's venv, uv, conda or pixi environment on its own, and has atomic saves, autosave and crash recovery. Install it with cargo, uv (PyPI), Nix, or the .deb, .rpm and .apk packages and static Linux binary on each release.
