    About Game Master Claude

    Start a new world with /new-game, where a questionnaire shapes a custom setting and ruleset, or import a PDF of a book you own and step into it. The harness keeps a campaign journal, a custom rulebook and a living world, and Claude narrates, rolls the dice and runs the table.

    You need Claude Code. The install script sets up everything on macOS and Linux.
