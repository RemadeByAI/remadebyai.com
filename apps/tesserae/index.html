    About Tesserae

    Compose dashboards from tiles (calendars, weather, photos, Home Assistant data and more) in the browser. Tesserae renders each frame on the server and sends it to e-ink panels of different sizes, so one server can run many displays around the house.

    What people say

    Tesserae has a community thread on the Home Assistant forum and was also posted to Hacker News and the Pimoroni forums. On the Home Assistant forum, users praise its e-ink friendly design and say its MCP integration lets Claude build dashboards quickly. One user found the interface very slow, and another hit a connection error with Home Assistant. Coverage is thin and mostly from early adopters.
