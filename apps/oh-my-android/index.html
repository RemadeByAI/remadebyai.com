    About Oh My Android

    Oh My Android has 48 always-visible test actions: dark mode, font and display size, language and RTL, TalkBack, layout bounds, animations, network speed, GPS, and fake calls and texts. A layout inspector shows sizes and gaps in dp for any app and can overlay a Figma export. You can read SharedPreferences and SQLite, clear data, open deep links and install APKs by dragging. It works with real phones too.

    It is a native SwiftUI app for Apple silicon Macs on macOS 26 or newer, installed with Homebrew or a signed download.
