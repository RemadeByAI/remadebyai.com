    About Spinlings

    Every card is one of a kind, with its own look, genes and traits, and you can fuse, trade and duel them. Battles play themselves; press 1 when a special fires for a Perfect hit. Generated rivals and a wandering trader fill in when no other player is around, and you can play entirely offline.

    Install it as a Claude Code plugin (two commands, or ask Claude to install it), then run /spin. Nothing is for sale, and cards have no cash value. You need Claude Code to play.
