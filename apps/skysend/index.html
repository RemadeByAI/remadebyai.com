    About SkySend

    Everything is encrypted with AES-256-GCM in the browser before it leaves the device, and the key travels in the part of the share link that browsers never send to the server. You can share files, whole folders, and notes with text, passwords, code or SSH keys, set expiry times and download limits, add a password, or send someone an upload link.

    It runs as one Docker container with SQLite, stores files locally or in any S3-compatible bucket, and has a command-line tool. You can host your own or use a public instance. It was inspired by Mozilla Send and PrivateBin.
