    About BackupZit

    A web console runs jobs for agents on Windows, Linux and Mac machines. It covers files, whole Windows disks and Linux systems with bare-metal restore, Proxmox VE, VMware ESXi and Hyper-V virtual machines (including instant recovery and automatic boot tests for Proxmox), SQL Server, PostgreSQL and MySQL databases, NAS shares and Microsoft 365 mail, OneDrive and SharePoint. Backups are deduplicated, compressed and encrypted, and can go to SFTP, S3, SMB, Azure, USB disks or an immutable hardened repository.

    The console needs a small Linux VM (Debian, Ubuntu, AlmaLinux or Rocky) and comes as a ready-made VM image, an installer ISO, an install script or Docker. The Mac agent is Apple silicon only (macOS 13+) and backs up files. The first public release was in October 2026, and MaxZit sells optional support.
