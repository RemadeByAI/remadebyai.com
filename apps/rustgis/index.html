    About RustGIS

    RustGIS is one native program drawn on the GPU, with no runtime to install. The ribbon follows the order of the work (Home, Data, Style, Edit, Analyze, View, Publish), with Layers and Browser panes and an attribute table. It includes more than 1,000 GeoLibre and Whitebox tools for terrain, hydrology, LiDAR and remote sensing, and sandboxed plugins.

    Every button is a command you can script from the command line or ask the optional AI assistant to run. The same app runs in the browser at web.rustgis.app and on phones and tablets for field work.

    How it was built with AI

    The README says RustGIS is "primarily built with Claude Opus 5.5", working under human direction and review. Checked 2026-11-22: 423 of 1,806 commits are co-authored by Claude.

    What people say

    Two tech sites covered RustGIS shortly after its first releases. Both like the small single download, the browser version and the built-in AI assistant, and It's FOSS notes the ribbon interface will feel familiar to office-suite users. The caveats are that it is very young, not proven at scale, and that QGIS still leads for professional cartography and Python plugin workflows. Coverage is thin and mostly descriptive rather than long-term hands-on testing.

    People like

    • Small single download that also runs in a browser tab
    • Familiar ribbon interface and a plain-language AI assistant that helps newcomers
    • AI and scripting built in from the start rather than bolted on

    Common complaints

    • Very new and not yet tested in production at scale
    • Far smaller plugin ecosystem than QGIS
    • Some formats need extra tools such as ogr2ogr installed
