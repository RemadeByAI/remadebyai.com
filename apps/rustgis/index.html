    About RustGIS

    RustGIS is one native program drawn on the GPU, with no runtime to install. The ribbon follows the order of the work (Home, Data, Style, Edit, Analyze, View, Publish), with Layers and Browser panes and an attribute table. It includes more than 1,000 GeoLibre and Whitebox tools for terrain, hydrology, LiDAR and remote sensing, and sandboxed plugins.

    Every button is a command you can script from the command line or ask the optional AI assistant to run. The same app runs in the browser at web.rustgis.app and on phones and tablets for field work.

    How it was built with AI
