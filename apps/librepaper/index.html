    About LibrePaper

    LibrePaper lets you create or upload a writing project, compile it in the browser, and share a link so others can highlight passages, comment and suggest edits at the same time, with live updates. It handles LaTeX, Typst, Markdown, Quarto, HTML and Org, so it suits academic papers as well as notes and reports.

    You can sign in to the hosted app at app.librepaper.org with GitHub or Google (new accounts start with a tutorial project in every format), use the desktop app, which can also keep scheduled ZIP backups of your projects, or run it yourself from one static binary on a laptop or small server. A command-line tool exports a complete copy of any project. It is made by political scientist Vincent Arel-Bundock.
