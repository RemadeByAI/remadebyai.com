    About neomd

    neomd is built for speed: everything is a shortcut away, with Vim motions to move around. Emails are written in Neovim and rendered from Markdown, unknown senders go to a screener first (like HEY), and a GTD-style flow helps you handle each email once. It supports IMAP and SMTP accounts, server-side tags, private notes on emails and OS keyring passwords.

    It runs in a terminal on Mac and Linux, with a package on the Arch AUR.
