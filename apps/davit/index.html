    About Davit

    Davit is a SwiftUI app for Apple's container platform, which runs each Linux container as a lightweight VM. It has a dashboard, container lists with live CPU and memory, logs, stats charts, a file browser and terminal for each container, image pulls and builds, volumes, networks, local DNS and Compose file import.

    It needs an Apple silicon Mac with macOS 15 or newer, and installs Apple's container platform for you on first launch if it is missing. It is also available through Homebrew (brew install wouterdebie/tap/davit).
