    About Ferry

    Ferry looks like a chat with yourself: paste a link, a shell command, a photo or a file on one device and it lands in a timeline every joined device can read, with a one-tap copy button. Files up to 64 MB are stored as uploaded, without re-encoding. There is no account; a new device joins by scanning a QR code, optionally gated by a shared password, and can be revoked later. Any message can be recalled from the server.

    It runs as one Go server with SQLite, usually via Docker Compose on an always-on amd64 or arm64 machine, and is meant to stay on a trusted private network over plain HTTP, not the public internet. Any browser works as a client; optional native apps exist for Android 8+ (APK in the releases) and iOS 26+ (FerryDrop on the App Store). There is no automatic discovery or background clipboard sync.
