    About Fresh

    Fresh is built to feel like a normal desktop editor: a menu bar, mouse support, familiar shortcuts, a file explorer, tabs and split views, and a command palette. It opens multi-gigabyte files quickly and has multiple cursors, block (column) selection, project-wide search and replace, code folding, language servers and a theme editor with dark themes.

    It started as a terminal editor and still runs there, and Fresh Desktop wraps it in its own window with installers for Windows, macOS and Linux. On Windows you can also install it with winget install fresh-editor.
