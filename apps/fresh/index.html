    About Fresh

    Fresh is built to feel like a normal desktop editor: a menu bar, mouse support, familiar shortcuts, a file explorer, tabs and split views, and a command palette. It opens multi-gigabyte files quickly and has multiple cursors, block (column) selection, project-wide search and replace, code folding, language servers and a theme editor with dark themes.

    It started as a terminal editor and still runs there, and Fresh Desktop wraps it in its own window with installers for Windows, macOS and Linux. On Windows you can also install it with winget install fresh-editor.

    What people say

    Coverage of Fresh is small but friendly: one well-received Show HN thread (December 2025), a few Linux news reviews and some blog posts. People keep saying it's easy to pick up, especially for anyone used to VS Code or nano, with smooth multiple cursors, a command palette, working mouse support and a fast feel, even on very large files. The criticism is about early Windows mouse bugs, a large dependency list and binary size, and some doubt about whether another terminal editor is needed next to micro and Helix. It's also not yet in most Linux distros' official repositories, so installing takes a few more steps.

    We couldn't check Reddit for this round-up.

    People like

    • Easy to start with: no modal editing, familiar to VS Code and nano users
    • Unusually smooth multiple cursors for a terminal editor
    • Command palette, file browser and mouse support work well
    • Fast and responsive, even with huge files

    Common complaints

    • Early mouse bugs on Windows (text selection in Windows 11)
    • Lots of dependencies and a large binary for a terminal editor
    • Not yet in most distros' official repositories, such as Debian
    • Some doubt that another terminal editor is needed next to micro, Helix and Kakoune
