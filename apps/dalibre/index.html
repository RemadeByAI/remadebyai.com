    About Dalibre

    Dalibre is a lighter front end for the book library Calibre already keeps: point it at a Calibre library folder (or let it find the one Calibre uses) and browse, search and organise your books, with the same files and database underneath so you can keep using Calibre alongside it. Libraries on network shares work too.

    It is written in Go with a native UI, ships as one binary for macOS, Windows and Linux, and updates itself from signed GitHub releases. Your own AI agents (Claude Code, Claude Desktop, Cursor) can work with the library through its open tools. It is a young project, started in November 2026.
