    About SaneBar

    SaneBar hides menu bar icons you don't need right now and keeps the important ones visible. Hidden apps open from an Icon Panel you can search, or from a second menu bar. It adds Touch ID lock, smart triggers and profiles. All former Pro features are now free.

    It needs an Apple silicon Mac running macOS 14 to 26. On macOS 27 it can't hide icons and points you to the system's own menu bar settings instead. The project is now community-maintained. Also available with Homebrew (brew install --cask sane-apps/tap/sanebar).
