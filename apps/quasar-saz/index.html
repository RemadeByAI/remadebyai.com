    About Quasar Saz

    Momo, a two-year-old cavapoo, typed on a keyboard, and Claude Code was told to treat every mashed key as an intentional design instruction. The result is a complete Godot game that no human designed. Version 1.1 adds some human bug fixes and usability changes; version 1.0 is the game exactly as it came out, bugs included.

    All graphics are drawn in code and all audio is synthesised from waveforms, with no image or sound files.

    How it was built with AI

    The README says Claude Code wrote all the code, drew all the graphics, synthesised all the audio and tested everything, with guardrail tools from the maker. Checked 2026-11-22: all 17 commits are co-authored by Claude.

    What people say

    The story of a dog whose random keystrokes Claude Code turned into games went viral, reaching the top of Hacker News and getting picked up by PC Gamer and many other outlets. Most people enjoyed it as a whimsical, creative experiment, and some took away a lesson that the scaffolding and feedback loops around the AI mattered more than the input. Sceptics said the dog adds nothing and called it random noise fed to a slot machine. Almost all the discussion is about the experiment rather than how good the game is to play.
