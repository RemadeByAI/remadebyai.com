    About Cinephage

    Cinephage brings together what usually takes Radarr, Sonarr, Prowlarr, Bazarr and Overseerr: monitoring and managing movies and TV series, indexers, subtitles from several providers, and discovery and smart lists. It also manages live TV and IPTV channels. Everything shares one SQLite database and one web interface that works on desktop and mobile.

    What people say

    Coverage is limited to self-hosting blogs and the Servers@Home community, and is mostly positive about the idea of replacing Radarr, Sonarr, Prowlarr and Bazarr with one database, one interface and one configuration. Writers say the code is solid for such a complex domain. The main caveats are that it is still a work in progress with rough edges, that monitoring is marked experimental, and that a single monolithic app may not isolate failures as well as separate services.

    People like

    • One app, database and configuration instead of a stack of separate services
    • Code quality seen as solid for a complex domain
    • Light footprint, with streaming options for watching right away

    Common complaints

    • Work in progress with rough edges; monitoring is experimental
    • All-in-one design may scale and isolate faults less well than separate tools
    • Few long-term hands-on reviews so far
