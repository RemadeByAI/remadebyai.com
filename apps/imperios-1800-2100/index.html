    About Imperios 1800–2100

    Build a village and advance it through five ages, each opening new buildings and units: the Steam age (1800-1870) with settlers, militia and palisades, the Electric age with foundries, markets and artillery, the Atomic age with armour and concrete, and on to 2100.

    There are no image, model, sound or font files at all: every PBR texture, mesh, shot and bar of music is generated in code from a seed, so the first start takes about 40 seconds while it builds the textures. There is no hosted version: you run it yourself with Node.js (npm run dev). The game is in Spanish.
