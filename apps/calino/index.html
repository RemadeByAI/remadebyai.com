    About Calino

    Calino is a calendar app that runs in the browser and talks directly to the calendar server you already use: Nextcloud, Baikal, Radicale, Fastmail, iCloud or any other CalDAV server, and JMAP servers such as Stalwart. It has month, week, 3-day, day, agenda and year views, drag-and-drop editing, a command palette where you can type something like "coffee on wednesday at 12" to create an event, tasks with priorities and recurrence, journal entries in Markdown, contacts from CardDAV, colour-coded categories and light and dark themes.

    There is no Calino account and no backend: your calendar data and settings stay in the browser, and it can be installed as a web app. Use the free hosted version at calino.io or run your own copy with Docker. Your server has to allow browser requests (CORS), or you can go through a proxy, including one the project hosts. An Android app is available as an APK from GitHub Releases, not from Google Play.
