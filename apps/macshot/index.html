    About macshot

    macshot lives in the Mac menu bar. One hotkey freezes the screen so you can select a region, mark it up with arrows, text, shapes, numbered markers or blur, and copy it straight to the clipboard.

    It also records the screen as MP4 or GIF with system audio and microphone, stitches scrolling captures into one tall image, reads text with OCR, can auto-redact emails, phone numbers and card numbers, and uploads to Google Drive, imgbb or any S3-compatible storage. It is a native Swift and AppKit app, also installable with Homebrew (brew install --cask macshot).
