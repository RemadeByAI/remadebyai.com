    About Focus

    Focus shows two streams side by side: the time you log (projects, entries, billable hours) and the time you spent, meaning which apps, windows, browser tabs and Claude Code or Codex sessions were in front of you. Drag a block of real activity onto the calendar to log it.

    There is a one-line timer bar that also lives in the menu bar, a week calendar where you draw, move and resize entries, and reports per project. Everything stays on your Mac. The download is for Apple Silicon. The repo has no licence file, so the code is visible but not open source.
