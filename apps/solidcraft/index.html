    About SolidCraft

    SolidCraft has sketches with its own constraint solver, and extrude, revolve, sweep, loft, fillet, chamfer, shell, holes, threads and patterns on an editable timeline. It also does parameters and configurations, assemblies with joints and motion studies, and sheet metal with flat patterns. It opens and saves STEP, IGES, 3MF, STL, OBJ and glTF.

    Its README calls it early but usable for simple parts. There are installers for Windows, Mac (signed and notarized) and Linux (AppImage, Snap and more), and a version that runs in the browser. A command-line tool and MCP server run the same commands.
