    About Bash Fighter

    The main mode is Last Fighter Standing, a battle royale for up to 20 players where the arena shrinks as the field thins. Timed Brawl and Stocks modes share the same simulation. There are no accounts: Play with a friend puts a code in the address bar, and anyone with the link joins, or watches.

    The makers say the project is early but live, with a server-authoritative match server running in production.
