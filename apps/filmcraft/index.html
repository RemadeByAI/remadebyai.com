    About FilmCraft

    FilmCraft is a timeline video editor written in Rust: bins, source and program monitors, multi-track editing, a Color workspace with scopes, and audio mixing with loudness meters. It imports most common video formats and uses hardware decoding on each platform.

    Every action is also a command that its CLI and MCP server can run, so an AI agent can cut, grade and export a project the same way a person does. The project calls itself alpha.

    How it was built with AI

    Checked 2026-11-22 in the repo's commit history: 1,431 of 4,204 commits are co-authored by Claude, and the repo has CLAUDE.md and AGENTS.md files. XDA and MakeUseOf report that ArtCraft's maker, Brandon Thomas, built the suite with Claude Opus 5.5.

    What people say

    FilmCraft was covered mostly as part of the ArtCraft suite launch, with one detailed hands-on review from ProVideo Coalition. The reviewer liked touches such as the built-in loudness meter and the shortcut editor, and was impressed at how far a Premiere-style clone had come. He found trimming and heavy timeline work unreliable, though, and doubted experienced editors would trust it yet. Tech press also stresses that the app is an early alpha built largely with AI.

    People like

    • Surprisingly far along for a free Premiere-style editor
    • Built-in loudness meter that is easy to reach
    • Well designed keyboard shortcut editor

    Common complaints

    • Trimming and extended timeline editing work poorly
    • Confusing colour coding for trim modes
    • Very early alpha; reviewers doubt professionals will rely on AI-built software yet
