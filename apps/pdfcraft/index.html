    What people say

    Coverage of PdfCraft is thin and mostly technical. A source-code walkthrough on PyShine praises its real security model and handy JSON-driven automation, while listing clear gaps: weak editing of existing text, Latin-only OCR, and a borrowed renderer. A user on AlternativeTo liked that it is open source with a Linux build but noted it is still alpha. Wider press on the ArtCraft suite calls the apps promising but not ready for production.

    People like

    • Security features are genuine rather than cosmetic
    • Scriptable automation, such as marking every mention of a phrase in one step
    • Open source with a Linux version

    Common complaints

    • Editing existing text is limited, especially for CJK
    • OCR only handles Latin scripts
    • Still alpha; fuzzing keeps finding crashes on malformed files
