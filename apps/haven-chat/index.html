    About Haven

    One person runs the server and everyone else joins with a code. Messages, files and voice stay on that machine. It runs in Docker with one command, or on Windows from a zip and a double-click, and on Linux or Mac with a start script. Friends join from the browser.

    The README says a group of friends needs about 100 MB of memory and almost no processor time, and it comes with themes, voice channels and screen sharing.
