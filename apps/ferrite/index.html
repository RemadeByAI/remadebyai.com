    About Ferrite

    Ferrite is written in Rust with egui, so it starts fast and stays light even on very large files. You can edit the raw text, the rendered page or both side by side, with scroll sync, Mermaid diagrams, multi-cursor editing, code folding, CSV cell editing, spell check, Zen mode and export to PDF or themed HTML. It keeps your files' encoding and line endings.

    Windows builds are signed. The app is developed and tested on Windows and Linux; the Mac build is not notarized and is described as experimental.

    How it was built with AI

    The README says: "This project is 100% AI-generated code. All Rust code, documentation, and configuration was written by Claude (Anthropic) via Cursor." The maker publishes the prompts and handover documents used to build it.

    What people say

    Ferrite drew a busy Show HN thread and a hands-on review from It's FOSS. People like that it is a fast native Rust app with built-in Mermaid rendering and an IDE-like set of tools for Markdown, and some note it avoids the usual egui look. Criticism covers missing features such as images in the rendered view and wikilinks, install problems on older Linux, a laggy split view, and unease that the code is largely AI-generated.

    People like

    • Fast native app written in Rust
    • IDE-style tools for Markdown, such as a terminal and Git status
    • Clean look that does not feel like a typical egui app
    • Built-in Mermaid diagram rendering

    Common complaints

    • Rendered view does not show images
    • Missing wikilinks and backlinks compared with Obsidian
    • Install and startup problems on some systems
    • Some users want clearer disclosure of heavy AI use
