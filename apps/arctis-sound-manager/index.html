    About Arctis Sound Manager

    SteelSeries does not make GG or Sonar for Linux, so this fills the gap. It splits your audio into Game, Chat and Media channels with a ChatMix slider, routes browsers and players automatically, and has a Sonar-style parametric EQ with over 350 game presets that can switch on by itself when a game starts. It also does spatial audio, mic noise removal, a separate stream mix for OBS, 30-second clips and headset controls such as ANC, sidetone and battery.

    It supports the Arctis Nova Pro, Nova Elite, Nova 7, 5 and 3, older Arctis 7, 9 and Pro models and GameBuds, and is built on PipeWire. One install script covers Arch, Fedora, Debian and Ubuntu, with a Distrobox setup for Bazzite and SteamOS. Parts of the code come from the earlier Linux Arctis Manager project.
