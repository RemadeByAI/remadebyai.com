    About Excaliself

    Excaliself wraps the open-source Excalidraw editor in a small self-hosted app that stores every drawing in your own Postgres database. You get auto-save, live collaboration by link with cursors and follow mode (for members or guests), a shared team space next to private spaces, a team shape library, folders, stars, search inside drawings, trash with restore, and import from Excalidraw+.

    Accounts are invite-only, with optional single sign-on through Google Workspace, Microsoft Entra ID or any OIDC provider. MCP clients such as Claude can find, read and create drawings, and their changes wait on the canvas until you apply them. A one-line Docker command starts a throwaway preview with example drawings.
