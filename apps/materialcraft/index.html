    About MaterialCraft

    MaterialCraft builds procedural materials in a node graph with live thumbnails, a 3D view and a 2D view. Noises and patterns tile seamlessly at any resolution, and only the nodes downstream of an edit are re-cooked.

    It saves native .sbs projects and exports base color, normal, roughness, metallic, height and ambient occlusion maps as PNG, JPEG, TGA, EXR, HDR and more. File, Send to TextureCraft puts a material on TextureCraft's shelf with its inputs still live. It is the youngest of these apps, and its README lists node behaviour and SBS save and load as the current focus.
