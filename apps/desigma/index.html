    About desigma

    desigma covers the everyday Figma workflow in a native desktop app with no web view: frames with auto layout, components with variants and properties, variables with light and dark modes, vector editing, prototyping with Smart Animate, keyframe motion, whiteboards and slide decks. Dev mode shows measurements and generates code in CSS, Tailwind, SwiftUI, Jetpack Compose, React, Flutter or Vue. It imports .fig files and Figma's API JSON, and live collaboration works by sharing a link, with no account.

    The project labels itself an early alpha. Builds for Windows (installer or portable zip), macOS (one .dmg for Apple silicon and Intel) and Linux are on the releases page; they are not code-signed yet, so the first launch shows a warning. An optional AI image edit feature uses your own OpenRouter key.
