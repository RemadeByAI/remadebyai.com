    About DRIFTWING

    Fly over snowy peaks, pine valleys, deserts, island chains and flower meadows that are generated as you go, under a sky that lingers at golden hour and fills with aurora at night. There is no way to lose: no fuel and no enemies. Version 2 adds six aircraft, from the glider to a jet and a helicopter, plus storms, discoveries, a world map, photo mode and shareable world seeds.

    WREN, the AI copilot, can set waypoints, fly for you, change the time of day or set up a ring course when you talk or type to it. The original single-prompt version 1 is still one click away in the launcher.

    How it was built with AI

    The README says version 1 was built from a single prompt to Claude Opus 5.5 with no human code edits, and version 2 is being built with the same model in phases. Checked 2026-11-27: 740 of its 750 commits are co-authored by Claude. The repo has no licence file.
