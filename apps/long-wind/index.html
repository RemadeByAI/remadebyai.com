    About Long Wind

    Combat has light and heavy combos, blocking and perfect parries, dodges, stance breaks and finishers, sword waves and lock-on, against archers, shield bearers, spearmen and assassins. It is built with three.js and WebGL and needs no install. The README is in Chinese with an English summary.

    Screenshots

    How it was built with AI

    The README says every line of code was written by Claude Opus 5.5 in Claude Code, with the first playable version done in about a day. The maker described what they wanted in Chinese, played and gave feedback; the design, code, debugging, tests and tuning were done by the AI. Character models came from Tripo AI and motion from Mixamo.
