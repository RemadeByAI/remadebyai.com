    Game Glance

    Alternative to Steam's Game Mode home, HLTB for Deck

    A Decky Loader plugin for Steam's Game Mode on handhelds that turns each game's page into a full-screen view with how long it takes to beat, play time and achievements, plus an optional new home screen.

    About Game Glance

    The game page shows full-screen art, HowLongToBeat times, your play time and achievements, and where the game comes from. Spotlight Home (off by default) replaces Steam's Home with one game at a time over its art, a row of recent games, all installed games including non-Steam ones, and Friends, News and Recommended tabs. It also adds touch and mouse control, a screensaver drawn from your games, and store info for games added by Heroic.

    Install it from Game Mode through Decky's Install plugin from URL; it updates itself from releases. It was tested on a ROG Xbox Ally running Bazzite and should work on a Steam Deck and other SteamOS-like devices.
