    About 38-0-0

    After each draft the game reveals whether your team made Europe or won the league and cups. An international mode drafts from past World Cup teams. It was inspired by the basketball draft game 82-0.

    It is free with ads between rounds, and a one-time $9.99 purchase removes them. In June 2026 it passed Fortnite to No. 1 in the UK App Store free games chart, with about 100,000 downloads and 1.8 million website visitors in its first week. The game uses the names of real Premier League clubs and players.

    How it was built with AI

    MobileGamer.biz reports that Deniz Sancar, who has no software engineering background, built the web version overnight with Claude Code and used the same tool to make the iPhone app.
