    About TelltaleDNS

    Every query in the log is tied to a named device and explained. Set blocklists, schedules, safe search and blocked services per device or group, and preview what a change would have done to yesterday's traffic before saving it. It supports encrypted DNS (DoT, DoH, DoQ) both ways, DNSSEC and full recursion.

    It is one static binary of about 13 MB that idles at around 14 MB of memory, for amd64, arm64 and 32-bit Pi OS. Install it with a script on any systemd Linux box or run it in Docker; a Pi and Kubernetes nodes can share one config.
