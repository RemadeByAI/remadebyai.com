    About TikZ Editor

    TikZ Editor shows your TikZ source next to the rendered figure and keeps the two in sync. You can open a single figure, a whole paper's .tex file or a Beamer presentation, then move, resize, align and group elements, draw nodes, arrows, curves, matrices and trees, and edit styles in an inspector. When you drag something, only the numbers in that coordinate change, so your line breaks and indentation stay as they were, and existing \foreach loops keep working. It needs no TeX install to show the figure, and it flags code errors as you type.

    It runs in the browser at tikz.dev, as a desktop app for Windows, macOS and Linux, and as a free iPad app. It exports SVG, PDF, PNG or standalone LaTeX, and imports SVG, Ipe and PowerPoint files. Very hacky TeX may not be read correctly, and pgfplots and some advanced constructs are not supported yet. The desktop app has an optional assistant that uses your ChatGPT account through Codex. There are no accounts or analytics.

    What people say

    Most of the discussion comes from its Show HN launch in June 2026, which drew 451 points and a lot of thanks from students and researchers who have long hand-tuned TikZ coordinates. People like that it can edit existing figures without rewriting the code. The main criticism is that new elements get absolute coordinates instead of TikZ's relative positioning and anchors. Beyond Hacker News, coverage is thin: one short user review and a few blog write-ups.

    People like

    • Edits existing TikZ figures without turning the code into machine-generated output
    • Saves the edit-and-recompile loop of nudging coordinates by hand
    • Free and open source, with web and desktop versions

    Common complaints

    • New and aligned elements use absolute coordinates rather than idiomatic relative positioning
    • No support yet for pgfplots or Typst's CeTZ, which some users asked for
    • An early Linux build showed a distorted grid for one user
