    About Tower of Time

    Made for Beginner's Jam Summer 2025. Choose from basic turrets, sniper towers, slowdown towers and splash damage towers, and spend energy both on building and on rewinding. It plays with keyboard or gamepad.

    Screenshots

    How it was built with AI

    The README calls it a vibe coding proof of concept: about 95% of the code was written by AI, using Augment Code and Cursor with Claude Sonnet 4 as the main model (plus some OpenAI o3 and Claude Opus 4). The prompts are published in the repo.
