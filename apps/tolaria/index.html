    About Tolaria

    Tolaria keeps your notes as Markdown files with YAML frontmatter in an ordinary folder, and treats that folder as a git repository, so you get version history and can sync through any git remote with no account or Tolaria server. Unlike a plain Obsidian-style editor, it is opinionated about structure: notes have types (such as projects, people or essays) and relationships, and there is an inbox, saved views, a command palette and a Notion-like block editor. It also has setup paths for Claude Code, Codex CLI and Gemini CLI, so AI agents can read and edit the vault and show up as their own git authors.

    The maker built it to run his own vault of more than 10,000 notes. Downloads are offered for Mac (Apple silicon and Intel, also via Homebrew), Windows and Linux (AppImage, DEB, RPM), and an iPhone and iPad version is in TestFlight beta. On first launch you can clone a getting-started vault that walks through the app.

    What people say

    Most of the discussion comes from its Show HN launch, where people liked the clean interface, the git-backed plain files and the Notion-style editor. Some called it the best parts of Obsidian and its plugins in one app. Others objected that it is a web-based Tauri app rather than a native Mac app, and early testers hit bugs and small editing annoyances. A knowledge-management writer highlighted its local-first design and its focus on AI tools, but noted it was desktop only at the time. Coverage is mostly first impressions from launch week.

    People like

    • Clean, good-looking interface
    • Plain Markdown files with git history and sync
    • Brings Obsidian-plus-plugins features together in one designed app
    • Built around AI agents working in the vault, not bolted-on AI

    Common complaints

    • A Tauri web-view app, not a native Mac app
    • Early bugs, including a frozen blank window for one tester
    • Small editor gaps such as code-block shortcuts and slow very large files
