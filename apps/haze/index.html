    About Haze

    Haze talks to the amp the way BOSS Tone Studio does, over USB MIDI, and edits every block live, with the chain order, A/B and undo. It adds what Tone Studio never had: a Linux version, a searchable library, setlists, a stage view, and a practice room with drums, a looper and a speed trainer. With no amp plugged in, the same rig plays on the computer through any audio interface.

    It is written in Rust and drawn on the CPU, using about 56 MB of memory. The maker calls it one person's daily amp editor, shared because it works rather than because it is finished; the Windows build is newer and less tested.
