    About SetShot

    Take a snapshot, change something (apply a macOS update, install software, adjust preferences), then take another. SetShot lists the recognized changes with a plain-English description, where to find each one in System Settings and, where possible, an Open in Settings button. Unrecognized changes show the raw name and old and new values, and can be submitted to grow its knowledge base.

    A journal keeps a searchable history of every change, snapshots can run on a schedule in the background, and you can compare against built-in baselines of fresh macOS 15, 26 and 27 installs to export everything you've changed. It never changes settings itself, and snapshots stay on your Mac. Runs on macOS 13 Ventura and later.

    What people say

    SetShot was launched through TidBITS, which its developer runs, so the main article is not independent, but it got a warm mention from John Gruber at Daring Fireball and an active TidBITS Talk thread. Users like the idea and call it a cool, useful way to see what changed in System Settings. Early testers reported slow snapshots, a missing cancel button, confusing baseline instructions, and in one case no recognized changes at all.

    People like

    • Clever, genuinely useful idea for tracking macOS settings changes
    • Free and open source
    • Helped users find settings that changed after updates

    Common complaints

    • Taking a snapshot is slow and lacks a cancel button
    • Some users saw unrecognized or no recognized changes
    • GitHub download page confused less technical users
