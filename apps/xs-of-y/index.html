    About Xs of Y

    Every run gets a new title (such as Voids of Deferred Maintenance), a new quest and a new mapping of runes, which secretly stand for Lisp expressions you inscribe on weapons and armour. The dungeon fights back in more ordinary ways too: spiders web you, slimes split, trolls regenerate, fire spreads through grass, and you can shove monsters into lava or chasms. The maker names Brogue as the main inspiration for its look.

    The maker says plainly that it is not finished: it is playable, but expect bugs and crashes, and the rune system has no documentation yet. It runs in the browser, or in a terminal on macOS and Linux via Homebrew (brew install nooga/tap/xsofy). It is written in let-go, the maker's own Clojure-like language.
