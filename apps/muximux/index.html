    About Muximux

    Muximux is for people who spend the day inside their self-hosted apps: click Sonarr or Plex and it opens in the dashboard, so you never leave it. Most self-hosted apps refuse to load in a frame; Muximux's embedding proxy rewrites headers and paths so they work. It has split view, themes, a command palette and an onboarding wizard.

    Version 3 is a ground-up rewrite in Go with the web interface built into one binary. It needs no database, and all settings live in one YAML file you can copy to move your setup.
