    About Locode

    Describe an app in plain English and Locode generates a complete React, Tailwind and Vite project, tests it with Playwright, fixes errors and lets you keep refining it with follow-up prompts. Everything runs on your own machine through Ollama, so there are no API keys or subscriptions.

    The ready-made download is a DMG for Apple Silicon Macs. It can also be run from source with Python and Node.
