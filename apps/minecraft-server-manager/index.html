    Alternative to Pterodactyl and Multicraft

    A free, self-hosted control panel for Minecraft servers running in Docker: create servers with a wizard, manage players, mods, backups and schedules, and use the live console.

    About Minecraft Server Manager

    It manages Minecraft servers built on the popular itzg/docker-minecraft-server image and aims to match commercial panels such as Pterodactyl, Multicraft and AMP in polish. It covers modpacks, worlds, backups, schedules, chat, the console and resource monitoring.

    Everything runs on your own machine with no paid services, and the whole panel is one folder you can copy to move it.
