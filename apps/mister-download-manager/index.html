    About Mister Download Manager

    The toolbar, categories, download list, progress window and browser button are where IDM users expect them. A browser extension for Chrome, Edge, Brave, Opera, Vivaldi and Firefox hands downloads to the app, it can save videos from web pages, and it opens magnet links and .torrent files. It comes in 86 languages, with no ads, trial or sign-up.

    Windows builds come as an installer or a portable zip for x64, ARM64 and 32-bit. Linux packages cover Ubuntu, Debian, Fedora, Arch and more; the Mac version is marked experimental.
