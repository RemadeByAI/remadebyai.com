    About DesktopWiki

    DesktopWiki gives a family or small team spaces, a page tree and a visual editor, the way classic team wikis work, plus a password manager for everyone's logins. You install it on one Windows PC, and everyone else opens it in a browser on a phone or another computer.

    There is no server, database or cloud account to set up: the whole wiki lives in one file you can back up by copying it. It can import from Confluence and can be opened up for use away from home.

    It is free for one person. Family (up to 6 people) is $49 a year, Team (up to 18) $99 and Business (up to 60) $199, on sale after the beta, with every feature in every plan. The host PC needs 64-bit Windows 10 (version 1809 or later) or Windows 11.
