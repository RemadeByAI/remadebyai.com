    About Taskbar Timer

    Each running timer shows on the taskbar next to the tray icons, with a progress bar in its own colour, so you can see what is left without opening anything. Up to ten can run at once, each with a label. There are four modes: a plain duration, counting down to a clock time, Pomodoro focus and break cycles, and alarms that repeat on chosen days.

    Type 2, 5, Enter for 25 minutes, or use the arrows and mouse wheel. A timer turns amber near the end and flashes red when done, with a Windows notification and a sound (four built in, or your own WAV). Global hotkeys open the panel and pause everything. It is one small .exe built with the C# compiler that ships with Windows and follows light and dark mode.
