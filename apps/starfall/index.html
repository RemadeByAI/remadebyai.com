    About Starfall

    Starfall has thirteen ship classes, true 3D movement with a move disc for setting altitude, formations, stances and control groups, plus production, research, resource harvesting and an AI opponent. Every hull, planet, nebula and effect is generated in code at runtime, so there are no image files at all; the only bought-in assets are free (CC0) sounds and music.

    It is an original game in the style of the classic 3D space strategy games, not a copy: it uses none of their art, sound, code or names. It needs a desktop browser with WebGL 2.

    What people say

    Coverage is thin and focuses on how Starfall was made: a Homeworld-style space strategy game built by Claude Opus 5 from a single prompt for about $633. Russian gaming site Shazoo praised the fully procedural visuals, ship detail and effects, but said gameplay and performance still leave a lot to be desired. An explainx.ai blog post was more sceptical of the 'utterly perfect' framing around the project.
