    About OpenAero DFW

    It is a six-degrees-of-freedom flight model flown over the whole Dallas-Fort Worth area: land a 737 on DFW 35C, take an F-16 past Reunion Tower, or fly the approach into Love Field in a Cessna. Weather comes from the current METAR report. There is no install and no account, with keyboard controls (pitch, roll, rudder, throttle, gear, flaps, brakes, autopilot, mouse yoke) and touch controls on phones and tablets.

    A player guide on the site explains the controls and approaches.

    How it was built with AI

    The README says the game is developed by three scheduled Claude Code agents (Scout, Builder and Keeper) that test, build and merge it with CI as the gate. Its commits carry Claude co-author trailers throughout (checked 2026-11-23).
