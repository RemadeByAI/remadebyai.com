    About Merran

    Merran is in alpha: there are only pre-release versions so far, and the maker asks you to back up its data folder before every update. Import recipes from websites, write your own or migrate from Mealie and other apps, then plan the week with serving counts, build shared shopping lists that combine quantities, and track pantry amounts and use-by dates. A cooking view gives step-by-step instructions, ingredient checklists and timers, and there is a browser extension and an API with scoped keys.

    It runs as one Docker container with SQLite built in, with Postgres optional, and works in the browser on phones, tablets and desktops. Recipes, planning, lists and the pantry work without AI; an optional assistant for imports, substitutions and suggested changes uses your own AI provider or endpoint. Sending lists to supported store carts, nutrition and voice need extra setup.
