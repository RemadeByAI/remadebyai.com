    About CUPS Admin

    macOS 27 turned off the CUPS web page at localhost:631, though printing itself still works. CUPS Admin puts the controls back in a SwiftUI app: list every printer, hold, release, move or cancel jobs, and set a queue's driver options as a form that is applied with lpadmin and read back. A cupsadmin command does the same from the terminal.

    It was built at Western Kentucky University for a fleet of about 1,000 Macs and ships as a signed, notarized installer for macOS 14 and later. The author notes it doesn't yet cover every page of the old web interface.
