    About Arrmada

    Arrmada replaces the usual stack of separate apps with one database and one web page. It handles movies and TV the way Radarr and Sonarr do (and can import their libraries), tracks ebook and audiobook series, lets family and friends request titles Overseerr-style, fetches or extracts subtitles, and can re-encode wasteful video to HEVC or AV1 overnight.

    It runs on a Linux server with Docker Compose (including Unraid) and connects to Plex and Jellyfin. The README calls it early days (v0.x) and suggests keeping backups.
