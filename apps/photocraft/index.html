    What people say

    PhotoCraft got press attention as part of the ArtCraft suite, a set of AI-built, open-source stand-ins for Adobe apps. Reviewers like that it is free, needs no account or internet connection, and looks familiar to Photoshop users. Hands-on testing of early alpha builds found real problems: no HEIC support, unreliable selections, and trouble saving layered files on a Mac. Coverage also raises wider questions about the quality, security and copyright status of code written mostly by AI.

    People like

    • Free and open source, with no account or cloud subscription needed
    • Familiar Photoshop-style layout that handles basic edits like colour correction and titles
    • Broad feature list for an alpha, including layers, masks and PSD handling

    Common complaints

    • Early alpha builds had bugs with selections, moving objects and saving
    • Could not open HEIC photos and was not optimised for Macs in testing
    • Doubts about the quality, security and copyright status of AI-written code
