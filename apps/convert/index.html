    About Convert

    Select files in Finder, pick Quick Actions, then Convert, and a small window offers only the formats that make sense: MP3, FLAC or Opus for audio, MP4, WebM or a GIF for video, HEIC, AVIF or WebP for pictures, PDF or Word for documents, and WOFF2 or TTF for fonts. The new file lands next to the original, and batches run one after another under one progress bar.

    Advanced settings (bitrate, resolution, quality, page size) are remembered per format. Audio and video use ffmpeg, which you install once with Homebrew. The same formats and naming rules also run on Windows (a signed installer) and Linux.
