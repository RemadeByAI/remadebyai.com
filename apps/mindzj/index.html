    About MindZJ

    MindZJ stores every note as a plain .md file in a folder on your own disk. It has live preview, source and reading modes, [[wiki links]] with backlinks, full-text search, a command palette, tabs and splits, math, Mermaid diagrams, snapshots of every edit, and a built-in mind-map editor.

    AI is optional: it can use Ollama offline, or Claude and OpenAI with your own key. Plugins run in a sandbox and follow an Obsidian-compatible API. It is built on Tauri, so the installer is about 10 MB.

    What people say

    Coverage is thin and split. A personal tech blog gave an enthusiastic overview of the app's light footprint, offline AI support and command-line tools, but it reads largely like a summary of the README. The author's launch post on the French site LinuxFr was voted down heavily, and commenters criticised the vibe-coded code base, dependencies committed to the repository and star counts they felt overstated the project's quality.

    People like

    • Small, native app that is lighter than Electron-based note tools
    • Local AI through Ollama and a command-line tool for managing notes
    • Free and open alternative to Obsidian with Markdown files on disk

    Common complaints

    • Seen as heavily AI-generated, which raises doubts about code quality and maintenance
    • Dependencies committed to the repository and other signs of rushed engineering
    • No built-in sync; users must rely on git, Syncthing or similar
