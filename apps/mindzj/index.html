    About MindZJ

    MindZJ stores every note as a plain .md file in a folder on your own disk. It has live preview, source and reading modes, [[wiki links]] with backlinks, full-text search, a command palette, tabs and splits, math, Mermaid diagrams, snapshots of every edit, and a built-in mind-map editor.

    AI is optional: it can use Ollama offline, or Claude and OpenAI with your own key. Plugins run in a sandbox and follow an Obsidian-compatible API. It is built on Tauri, so the installer is about 10 MB.
