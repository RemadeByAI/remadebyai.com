    About Mirli

    Mirli (formerly Soundbox) is aimed at sound for games, videos and stories more than at voice alone. Describe a sound effect or a piece of music and it generates it; give it a lyric sheet and it makes a song; type a script and it voices each line with saved or cloned voices. Everything lands on a multi-track timeline with lanes for narration, dialogue, music and effects, where you can mix down and export. It can also extend or cover a track and split audio into stems.

    It runs open-weight models such as Stable Audio 3.0 and ACE-Step through its own native runtime, with no account, no credits and no Python setup, and works offline once a model is downloaded. Each model's licence and commercial-use terms are shown before you download it. An NVIDIA GPU is the main target; it also runs on the CPU, slowly, and the Mac installers are not yet confirmed with the main models. There is a local HTTP API and an MCP server so Claude Code or Cursor can add sounds to a project.
