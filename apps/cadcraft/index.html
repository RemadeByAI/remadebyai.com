    About CADCraft

    CADCraft follows the classic drafting workflow: type a command such as LINE, click points or enter coordinates, and use object snaps, polar tracking, ortho, grips and right-click to repeat. It has layers, hatches, blocks with attributes, every DIM command with dimension styles, multileaders, tables and paper-space layouts.

    It reads and writes DXF natively (R12 through 2018) and opens and saves DWG (R13 through 2018) through the open-source acadrust library, with SVG and PNG export. Its README calls it "in early, fast development"; release builds (v0.8.0 on 2026-11-22) are code-signed for Windows and macOS.
