    About VibeNVR

    VibeNVR manages IP cameras, continuous and motion-triggered recordings, motion detection (OpenCV, ONVIF camera events or AI detection), camera groups and a unified event timeline, with notifications and MQTT. It has role-based access control and authenticated media.

    It runs in Docker containers on a Linux machine. It sends anonymous usage statistics by default, which you can turn off.
