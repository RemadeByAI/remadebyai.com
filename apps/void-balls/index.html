    About Void Balls

    Version 0.1.0 has 15 upgrade cards and a locked seven-colour neon look. It is built in Unity and still in development.

    How it was built with AI

    The maker's launch devlog says Claude Code (Opus) wrote all of the roughly 29,000 lines of C#, reviewed by a human, using Unity MCP. Sprites were generated through Replicate and audio with ElevenLabs.
