    About FreeFlow

    Hold the Fn key, talk, and FreeFlow types what you said into whatever text field you are in. It cleans up filler words and spelling using nearby app context and your own vocabulary list, and Edit Mode can rewrite selected text from a spoken instruction such as "make this shorter".

    It uses a free Groq API key by default, or any OpenAI-compatible provider including local models through Ollama or LM Studio. There is no FreeFlow server. It works on Apple Silicon and Intel Macs.

    How it was built with AI

    Zach Latta's original README (February 2026) said he "vibe-coded" FreeFlow over a weekend. The project keeps an AGENTS.md file for AI coding agents, and 97 of its 511 commits (checked 2026-11-21) are co-authored by Claude.
