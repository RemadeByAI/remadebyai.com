    About Faro

    Faro connects to SFTP, FTP and FTPS servers, S3-compatible storage such as AWS S3, Cloudflare R2 and Backblaze B2, WebDAV and Nextcloud, and cloud drives like Dropbox, OneDrive and Google Drive. You get two panes side by side with drag and drop, a transfer queue with pause, resume and bandwidth limits, folder syncs you can preview first, a disk usage view, and an SSH terminal in the same window. You can edit remote files in your own editor and import saved sites from FileZilla, PuTTY or your SSH config.

    On Windows you can mount a server as a folder in Explorer, with files downloaded only when you open them. There's also a command-line tool and an optional bridge that lets a local AI agent use your open sessions, with each command needing your approval by default. Installers are available for Windows, macOS (Intel and Apple silicon) and Linux, but they aren't code-signed yet, so Windows and macOS show a warning on first launch.
