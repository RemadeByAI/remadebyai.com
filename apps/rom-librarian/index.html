    ROM Librarian

    Alternative to clrmamepro, RomVault

    A desktop app for tidying retro game ROM collections: batch rename with No-Intro DATs, compress to ZIP or 7z, convert disc images to CHD and keep EmulationStation lists in sync.

    About ROM Librarian

    ROM Librarian has tabs for each cleanup job. Rename uses regular expressions and presets to strip region and dump tags, with a live preview and undo. DAT Rename matches files (even inside ZIPs) against No-Intro DAT files by CRC32, MD5 and SHA1. Compression batch-packs or unpacks ZIP and 7z, and Conversion turns CUE/BIN and ISO disc images into compressed CHD files for MAME and RetroArch.

    Renames also update EmulationStation/RetroPie gamelist.xml files and the CUE sheets that point at BIN files. The Windows build is a portable zip with no Python needed; Linux runs it from source and has a command-line mode. It is for organizing games you own.
