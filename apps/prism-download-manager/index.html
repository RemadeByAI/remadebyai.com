    About Prism Download Manager

    Prism splits each download across up to 32 connections, writes straight to the final file and resumes after a crash, sleep or a dropped connection, checking that the file on the server has not changed. An extension for Chrome, Edge, Brave, Opera, Vivaldi and Firefox passes downloads to it, and it handles HTTP, FTP, HLS and DASH streams, BitTorrent and magnet links. Video and audio from YouTube and the other sites yt-dlp supports can be saved as MP4 or MP3, and it can fetch AI models from Hugging Face.

    There are queues with schedules and speed limits, categories, batch downloads, a site grabber, a clipboard monitor and a mini window. Installers are for Windows 10 and 11, macOS 11 or later (Apple silicon and Intel) and Linux (deb, rpm, AppImage). They are not code-signed, so Windows and macOS warn on first start. No ads, account or telemetry.
