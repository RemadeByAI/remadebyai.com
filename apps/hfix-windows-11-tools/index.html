    About HFix Windows 11 Tools

    HFix turns off Windows telemetry and advertising settings in one click, cleans memory and disk, manages startup programs and services, and keeps an eye on running programs and network use from the tray. Every change is backed up and can be undone, and it can make a restore point first. It deliberately has no switches that weaken security: Defender, Windows Update, CPU protections and UAC stay as they are.

    It is one portable exe that installs itself and also runs on Windows 10 (1809 and later), hiding the settings that exist only on Windows 11. The interface and README are in Turkish, with an English section.
