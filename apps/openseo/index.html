    About OpenSEO

    OpenSEO covers the main SEO jobs without a big monthly subscription: keyword research, rank tracking, competitor insights, backlinks, site audits and tracking how AI assistants mention you. Instead of a flat fee you bring your own DataForSEO API key and pay only for the data you use.

    You can self-host it with Docker, on Cloudflare or through EveryApp, or use the hosted version, which you can try free and which has a $10 a month subscription. Its MCP server and agent skills let Claude Code, ChatGPT, Codex and other agents work with your SEO data.

    What people say

    OpenSEO is seen as a lean, open-source alternative to Semrush and Ahrefs, and users on Product Hunt praise its clean interface, value for money and MCP support for AI agents. The main criticism is that calling it free is misleading, because the data comes from the paid DataForSEO API and costs build up once you start using it. Detailed independent reviews are still few, and much of the buzz is launch posts and GitHub star counts.

    People like

    • Clean interface without upsell clutter
    • Pay-as-you-go pricing is good value compared with big SEO suites
    • MCP server lets AI agents work with your SEO data

    Common complaints

    • Not truly free: it relies on the paid DataForSEO API
    • Only Google Analytics is supported, no privacy-focused analytics like Plausible
    • Few in-depth independent reviews so far
