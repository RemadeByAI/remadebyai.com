    Zigzag

    Alternative to Arc

    A small, native Mac browser for people leaving Arc, with spaces, pinned tabs and split view. It runs on Safari's WebKit engine rather than Chromium, yet installs Chrome Web Store extensions.

    About Zigzag

    Zigzag keeps tabs in a sidebar grouped into spaces, each with its own color, pinned tabs and folders, plus favorites, profiles, a command bar, split view for up to four pages and a small pop-up window for quick links like Little Arc. Importing from Arc brings over spaces, pinned tabs, favorites, history, passwords and sign-ins, and it can also import from Chrome, Safari, Firefox, Zen and others.

    Unlike most Arc replacements it is not built on Chromium: it's a Swift app on the WebKit engine that ships with macOS, about 35 MB installed, so engine security fixes come with macOS updates. Chrome extensions such as 1Password and Bitwarden install from the Chrome Web Store, though a few Chrome extension APIs are still missing. It has a built-in ad blocker, cookie banner refusal and dark pages, with no account or telemetry. It needs macOS 15.4 or later and has no sync between Macs yet.

    What people say

    Zigzag launched on Show HN in mid-November 2026 and on Product Hunt, and the comments so far are mostly from early users switching away from Arc or Zen. People describe it as very fast and smooth, light on memory, and close to the Arc way of working, and extension developers liked that Chrome extensions install without changes. The doubts are about trust rather than features: several commenters are wary of a heavily AI-written browser from a solo developer and whether it will last. Coverage is young and made up of launch-week comments, not longer reviews.

    People like

    • Feels very fast and smooth, with no jank in the sidebar or space switching
    • Uses far less memory than Chromium- or Firefox-based Arc clones
    • Chrome extensions install from the Chrome Web Store on a WebKit browser
    • Spaces and profiles work well for people coming from Arc

    Common complaints

    • Some don't trust a browser written mostly with AI where security matters
    • Worry about relying on a solo developer's project long term
    • Missing a few Arc features, such as Portrait mode screenshots, and sync between Macs
