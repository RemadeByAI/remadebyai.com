    About zest

    Fig's popup autocomplete for the terminal was folded into Amazon Q and then Kiro CLI. zest brings the same idea back as a small free app: start typing a command and a popup lists its subcommands, options, files, folders, git branches and npm scripts, with a short description of each.

    It knows about 1,500 commands out of the box and works in Terminal, iTerm2, Ghostty, VS Code and Cursor, taking on your editor's theme where it can. Install it with a one-line script or Homebrew. Needs macOS 14 on Apple silicon and zsh.
