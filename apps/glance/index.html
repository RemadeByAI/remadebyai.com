    About Glance

    Glance lets a coding agent publish a page, dashboard or app to a live URL with one command (glance deploy). You leave comments on the page in the browser, much like in a Google Doc, and the agent reads them and fixes the page.

    You host it yourself on Cloudflare's free tier. It works with Claude Code, Cursor, Codex, Cline, Aider or any agent that can run a shell command, every link needs a login, and optional Slack notifications tell you about new comments.

    How it was built with AI

    Glance's commit history shows it was built mostly with Claude: 206 of its 251 commits (checked 2026-11-21) are co-authored by Claude models.
