    About SuperCmd

    SuperCmd opens from one shortcut and runs existing Raycast extensions without changes, and can import a Raycast backup. It also has hold-to-speak dictation, read-aloud for selected text, AI chat with the provider of your choice, clipboard history, snippet expansion, quick links, notes, a drawing canvas, file search and 24 window-tiling commands.

    The open-source v1 on GitHub is free under the MIT licence. Its website sells a newer v2 for a one-time $19.99 (covers 3 Macs, 7-day free trial).
