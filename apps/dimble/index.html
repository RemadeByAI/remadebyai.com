    About Dimble

    Dimble sorts menu bar icons into Visible, Hidden and Always Hidden. You arrange them in a layout editor with real icon previews or by Command-dragging in the bar, and hidden icons come back on a hover, a click, a keyboard shortcut, or as tiles in a panel under the menu bar. Menu bar search (Option-Command-K) opens any icon's menu by name, and it can keep Live Activities visible, set behaviour per display, tighten icon spacing and add separators, app launchers and stand-ins for system items such as media controls and AirDrop.

    It needs macOS 27, because it drives the native hiding built into the rebuilt macOS 27 menu bar through a private Apple framework, so a macOS update could break hiding. It asks for Accessibility (Screen Recording is optional, for animations), has no account or analytics, and installs from a notarized DMG or with brew install --cask dimble. It was called Pelmet until version 0.3.1 and is still in beta.
