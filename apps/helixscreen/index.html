    About HelixScreen

    HelixScreen puts the features that are usually stuck in a browser tab on your printer's screen: a dashboard you can arrange with 40+ widgets, bed mesh visualization, input shaper graphs, print history, and 11 multi-material systems.

    It is light enough to run on the printer's own board or a spare Raspberry Pi, or as a remote screen on another device pointed at the printer's Moonraker. Version 1.0 supports nine printer platforms in nine languages.
