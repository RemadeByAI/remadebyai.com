    About Idle Tactics: Ascension

    It took first place out of 72 entries in VibeBlitz, a four-week game jam for AI-built games run by vibecode.game (Yield Guild Games) with Animoca Brands' Minds. It is single player and built in Unity for the web.

    How it was built with AI

    Its vibecode.game listing says it was built with Claude and a Minds AI agent (Mister.code). IT Brief covered its jam win.
