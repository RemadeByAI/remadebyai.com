    About Opensidian

    Opensidian is a clean-room remake of Obsidian's behaviour built with Rust and Tauri: it works with the same vault folders, and has a graph view, canvas, themes and community plugins. It is not affiliated with Obsidian and contains none of its code.

    Linux builds come as AppImage, Flatpak, RPM and DEB, and there are Mac builds for Apple silicon and Intel. The project describes itself as under heavy development.

    How it was built with AI

    The README says Opensidian "was built predominantly with AI models. Nearly all of the code, the design docs, and this README were written by Claude" under one human maintainer.
