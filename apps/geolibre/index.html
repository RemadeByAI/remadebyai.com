    About GeoLibre

    GeoLibre opens geospatial data and keeps it on your machine. Its 1,000+ geoprocessing tools (terrain, hydrology, LiDAR, remote sensing and vector analysis) run in WebAssembly with no server, and a project can be shown with MapLibre, Mapbox, CesiumJS or the ArcGIS Maps SDK, even side by side.

    The full app runs in the browser at web.geolibre.app, and there are desktop installers, the Microsoft Store and Mac App Store, iPhone and Android apps, and Python and R packages for notebooks.

    What people say

    GeoLibre's 1.0 release was a popular Hacker News story, and it has at least one detailed independent write-up. People are impressed that a capable GIS runs entirely in the browser and recommend trying the live demo. Criticisms include file-loading errors and stalls with large files in the web version, a sense that it is not yet a full QGIS replacement, and some pushback on the marketing language and the low-contrast website.

    People like

    • A capable GIS that runs right in the browser, with a live demo worth trying
    • Careful handling of projections, including other planets
    • Python and Jupyter integration feels complete

    Common complaints

    • Large files can stall or exhaust browser memory
    • Some testers hit file loading errors in the web version
    • Not yet a replacement for heavy QGIS workflows
    • Marketing copy and low-contrast website drew criticism
